# Project notes (persistent memory)

## What this repo is
Full-SSR video archive viewer: FastAPI + Jinja2 + boto3 browse tree over an
S3-compatible bucket, plus a Vanilla-JS accessible modal video player.

## Backend notes
- The archive was exercised against **Garage**; any S3-compatible endpoint works.
- Configuration is environment-only; see `env.example`.
- Camera names and clip counts of a live deployment are not recorded here.
- Key layout: `<common_prefix>/<camera>/<YYYY>/<MM>/<DD>/<HH>/<MM>-<SS>.mp4`, i.e. the
  filename is **minute-second**, the hour comes from the folder name.
  Truncated recordings end in `-truncated.mp4`.
- Garage gotchas:
  - Presigned URLs need `signature_version="s3v4"`; the default (SigV2) yields
    `403 Forbidden: Garage does not support anonymous access yet`.
  - Range requests (`bytes=0-1023`) work and return 206 + `Content-Range`.
  - `list_buckets` works; keys are path-style.
- Credentials in `.env` are read-only.

## Conventions
- `requirements.txt` is generated by `pip-compile` from `requirements.in`
  (`~/.local/bin/pip-compile requirements.in`). Never hand-edit pins.
- Docker is unavailable in this sandbox (iptables permission denied), so tests
  use `moto.server` as a fake S3.
- Navigation must never scan the whole bucket: one `ListObjectsV2`
  (Prefix + Delimiter='/') per calendar level.
- Never add the `muted` attribute to the player; audio beats autoplay.
