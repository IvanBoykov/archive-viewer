# Project notes (persistent memory)

## What this repo is
Full-SSR video archive viewer: FastAPI + Jinja2 + boto3 browse tree over an
S3-compatible bucket, plus a Vanilla-JS accessible modal video player.

## Archive layout
- Key layout: `<common_prefix>/<camera>/<YYYY>/<MM>/<DD>/<HH>/<MM>-<SS>.mp4`,
  i.e. the filename is **minute-second**, the hour comes from the folder name.
  Truncated recordings end in `-truncated.mp4`.
- An hour holds 0 to 60 clips; whole hours, days and months can be empty.
- S3-compatible backends to expect: Garage, MinIO, Ceph, AWS.
  - Garage and MinIO need `signature_version="s3v4"` for presigning; botocore's
    default for S3 is SigV2, which Garage rejects with `403 Forbidden: Garage
    does not support anonymous access yet`. `PRESIGN_SIGNATURE_VERSION` in
    `app/s3.py` pins s3v4 for every browser-facing URL.
  - Range requests (`bytes=0-1023`) return 206 + `Content-Range`.
- All configuration is environment-only (see `env.example`); nothing about a
  deployment belongs in this file.

## Conventions
- `requirements.txt` is generated by `pip-compile` from `requirements.in`
  (`~/.local/bin/pip-compile requirements.in`). Never hand-edit pins.
- Tests run against `moto`'s fake S3 (no network, no real bucket), so no
  Docker or S3 credentials are needed to run them.
- Navigation must never scan the whole bucket: one `ListObjectsV2`
  (Prefix + Delimiter='/') per calendar level.
- Never add the `muted` attribute to the player; audio beats autoplay.
- `app.main` exposes `app` through a module-level `__getattr__` (PEP 562), not a
  module-level `app = create_app()`. Importing the module must stay free of side
  effects so `tests/conftest.py` can import it in a fresh clone with no `.env`;
  `uvicorn app.main:app` still builds it and still exits on `ConfigError`, because
  uvicorn resolves the attribute after the import.
- `load_dotenv()` is called inside `create_app()` and searches upwards from
  `app/main.py`, not from the working directory. A `.env` next to the checkout is
  therefore used regardless of where uvicorn is started from, and a clone without
  one fails fast. Keep any test that asserts "no configuration" away from the
  checkout itself (see `tests/test_import_without_config.py`, which runs against a
  copy of `app/` in `tmp_path`).

## Empty common prefix (`ARCHIVE_COMMON_PREFIX=""`)
- Supported: cameras sit at the bucket root, keys are `<camera>/<YYYY>/...` with
  **no leading slash**. An S3 key starting with `/` addresses a different object.
- `join_prefix()` is for directories only (it appends a trailing `/`); build clip
  keys as `join_prefix(...) + filename`.
- The camera list always lives at the site root `/`, so `build_path(common)` is
  `/` in both modes; a camera page is `/cam/` when the prefix is empty.
- With `Prefix=''`, `ListObjectsV2` also returns a `/` CommonPrefix when a
  degenerate `/`-keyed object exists; it is filtered as out-of-layout.
- `ARCHIVE_COMMON_PREFIX` unset means the default `archive`; explicitly empty
  (or `/`) means root. `Settings.from_env` distinguishes them by key presence.

## Out-of-layout folders never link
Listing used to call `int(name)` directly, so a stray folder such as
`<prefix>/<camera>/latest/` returned HTTP 500 (pre-existing bug, surfaced by running
the empty-prefix config against real Garage). `browse._directory_entry` now
validates each folder against the level regex, refuses ambiguous four-digit
camera names, and catches `ValueError`; such entries get `url=None` and render
as `.tree__plain` text. Traversal (`parse_path`, next/previous) was already
strict and still 404s.

## Period navigation (month and day pages)
- Levels are named after the folders they list: LEVEL_DAYS is the month page,
  LEVEL_HOURS the day page. `_PERIOD_LEVELS` maps them to PERIOD_MONTH/PERIOD_DAY.
- `archive.period_navigation` reuses `find_next_hour`/`find_previous_hour` with
  anchor hours placed outside the current period: back = first day 00:00,
  forward = last day 23:00 (last day via `calendar.monthrange`, so February is
  correct). Listing pages have no hour of their own, hence the extremes.
- `browse.PeriodRef` carries camera/year/optional-day. Keeping day separate is
  what guarantees a month page links to a month page; do not pass HourRef URLs
  to those templates.
- `partials/period-nav.html` is included twice via `{% with nav_position=... %}`
  (a bare `{% include ... with x=1 %}` is invalid Jinja). Both landmarks need
  distinct aria-labels.

## Camera page (months grouped by year)
- `LEVEL_YEARS` is the camera page. `BrowseService._year_groups` turns its year
  entries into `YearGroup` records and lists each year's months with one extra
  `list_level` call per year. Never walk deeper than that.
- Entries that are not years (stray folders, files) stay in `context.entries`
  and render in the normal `.tree` nav, so grouping cannot hide data.
- `browse.html` renders `context.year_groups` first, then `context.entries`.
  The `<h2>` per year links to the year page, which still exists as its own
  listing and breadcrumb step.
